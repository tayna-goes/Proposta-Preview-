## ✨ Sobre o projeto

Este projeto é um **portfólio audiovisual moderno**, desenvolvido para profissionais que desejam apresentar seus trabalhos de forma visual, elegante e impactante.

O layout foi pensado para proporcionar uma experiência mais imersiva, utilizando:

- Tipografia em destaque;
- Animações suaves;
- Efeito de parallax;
- Cursor personalizado;
- Galeria individual para cada projeto;
- Layout totalmente responsivo;
- Formulário de orçamento integrado ao WhatsApp.

O objetivo é criar uma apresentação profissional que valorize os projetos e facilite o contato com novos clientes.

---

## 🚀 Funcionalidades

### 🖱️ Cursor personalizado

O projeto possui um cursor customizado que acompanha o movimento do mouse.

Além disso:

- A bolinha aumenta ao passar por elementos interativos;
- Possui animação suave;
- Nos projetos, exibe a ação **"VER"**;
- É automaticamente ocultado em dispositivos móveis.
